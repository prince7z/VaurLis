sequenceDiagram

    participant User
    participant Frontend
    participant API as Express API
    participant Auth as JWT Middleware
    participant Logic as Route Logic
    participant DB as MongoDB
    participant External as External Services

    User->>Frontend: Action Request

    Frontend->>API: HTTP Request + JWT

    API->>API: CORS + Helmet + Rate Limit

    API->>Auth: Verify JWT Token

    Auth->>DB: Load User

    DB-->>Auth: User Context

    Auth-->>API: Authorized Request

    API->>Logic: Execute Business Logic

    alt Payment Flow
        Logic->>External: Razorpay API
    else Upload Flow
        Logic->>External: Cloudinary Upload
    else OTP Flow
        Logic->>External: SendGrid Email
    end

    Logic->>DB: Read/Write Data

    DB-->>Logic: Database Response

    Logic-->>API: Result

    API->>DB: Store Audit Logs

    API-->>Frontend: JSON Response

    Frontend-->>User: UI Update
